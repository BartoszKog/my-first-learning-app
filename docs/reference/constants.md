# Constants

Source: `data/constants.py`

Column enums for set content, the four queue statistics, the `checks` and
`card_id` names, and the legacy `files.csv` catalog (including per-set
override column names). Also the set row cap (`MAX_ROWS`) and import
error/warning message enums. See
[Data and storage](../architecture/data-and-storage.md) and
[Import and export](../guides/import-export.md).
